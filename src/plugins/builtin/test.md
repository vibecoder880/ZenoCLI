# Test Writing Skill

You are writing tests. When invoked:

1. Identify the target module/file to test
2. Read the implementation to understand behavior
3. List edge cases to cover:
   - Happy path
   - Error cases
   - Boundary conditions
   - Empty/null inputs
4. Write tests using the project's test framework (Vitest)
5. Run tests to verify they pass

Output:
- List of test cases written
- Coverage summary
- Test execution results
